# P0 Core Loop Improvement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove runtime image generation from the child-facing game loop, make successful matches immediately rewarding and non-blocking, and ensure displayed learning progress reflects only words the child actually practiced.

**Architecture:** Keep the existing client-side Next.js App Router architecture and localStorage persistence. A successful match will immediately create a globally deduplicated text-first `WordCard`, record a separate per-level practice entry, play speech, and show a short in-board success banner; image APIs remain available only as internal content-production infrastructure. Pair selection and progress display will use the per-level practice record, while lightweight attempt statistics will produce meaningful completion stars.

**Tech Stack:** Next.js 16 App Router, React 19 client components, TypeScript, localStorage, Playwright Test, existing CSS and Web Speech/Edge TTS fallback.

**Implementation status:** Completed and verified on 2026-09-19. All 10 automated tests, TypeScript checks, production build, and landscape visual QA passed.
